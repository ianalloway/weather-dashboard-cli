# Weather Dashboard CLI

A simple command-line interface for checking real-time weather information.

Install the dependency with `python -m pip install -r requirements.txt`. Run `python main.py Quito` to look up a city or `python main.py 0 0` to query coordinates directly.

## Features
- Fetch current weather by city name
- Display temperature, humidity, and conditions
- Support for multiple units (Celsius/Fahrenheit)
